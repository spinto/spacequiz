# Space Quiz

This is a simple quiz application you can run for events and other promotion activities.

The quiz questions are about Space, the European Space Agency and Earth Observation topics.

NOTE: The quiz is unrelated to the European Space Agency and something I have developed in my own spare time. I take no responsaiblity on the correctness of the questions and aswers, but please raise an issue if you find some oblivious mistake and I will try to correct it.
